## Academic provenance

The source register in foundation.v0.3.json records the USC programme P4202101, Fundamentos de Sistemas Aéreos no Tripulados, academic year 2023/2024. The source is an academic guide, with validation_status official_historical_reference. The PDF is a copy of the USC programme published by Galicia Drones; relevant material is on PDF page 1 (objectives, general contents and Bloque I). It is not represented as the current 2026/27 guide.

Source: https://www.galiciadrones.es/wp-content/uploads/2023/10/Guias-Docentes-USC_UVIGo-23_24.pdf

Four categories remain distinct:

1. Curriculum coverage and historical source identity.
2. Topic-specific learning objectives labelled pedagogical_adaptation, not literal USC objectives.
3. Proposed graph relationships labelled derived_from_curriculum, with rationale and source reference.
4. Technical development pending authorized teaching material; no technical quiz answers introduced.

Each Topic has stable_id, course_id, block_id, title, source metadata, adapted objectives, concept_ids, skill_ids, prerequisite_concept_ids, academic status and an MDX body. Skill and prerequisite arrays are empty because the guide does not establish specific Topic-level skills or prerequisites. The source registry can be replaced or extended for future academic years without changing personal-data IDs.
