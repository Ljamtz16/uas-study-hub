# V0.2 — Active Recall, Quiz and evidence-driven mastery

Implementation continues from baseline `201acb6` on local branch `feature/v0.2-learning-loop`.

## Scope and decisions

- The Golden Topic has a versioned recall prompt and two quiz placeholders (multiple choice and true/false). They demonstrate the workflow and explicitly do not certify technical knowledge.
- Recall accepts a written response or mental reflection and self-ratings 0, 0.5 and 1. Quiz scoring is correct answers divided by total, with incomplete or invalid answers rejected.
- Each submitted attempt appends existing `LearningEvidence` with its content source/version and private response or answers in existing metadata. Evidence and derived progress are written in one Dexie transaction.
- Schema v1, frozen contracts and mastery configuration remain unchanged. No migration, backend, remote dependency, AI, authentication, synchronization or deployment was added.
- Hydration recalculates mastery from stored evidence while retaining V0.1 records. Study refreshes the evidence counters immediately.
- The existing mastery formula, recent-attempt aggregation and status thresholds are reused. Study alone yields 10/100; full Study + Recall + Quiz yields 65/100 and understood. Mastered still requires successful spaced reviews.
- Dashboard keeps the existing ranking bands. The sequential candidate remains available while a topic is not mastered. Its local action explains Study, Recall, Quiz or continuation, using attempt existence rather than positive score to determine completed activities.
- The service-worker cache version advances to v0.2 so existing installations can obtain the new UI. IndexedDB is untouched by cache replacement.

## Coverage

- R-01 through R-05: study-only status, recall/quiz effects, configured understood thresholds and successful spaced review separation.
- Invalid/sparse quiz answers, normalized scoring, zero-score activity completion and recommendation band preservation.
- Database close/reopen preserves recall/quiz records, personal notes, sessions and earlier study evidence; hydration reconstructs mastery even when the saved score is stale.
- Browser flow covers course navigation, Study, Recall, Quiz, feedback, reload persistence, dashboard continuation and offline operation. Existing V0.1 browser tests remain included.

## Limitations

Academic content is still placeholder material. Written responses are stored with submitted attempts; unsubmitted drafts are not saved. Review scheduling and application activities are outside this increment, so mastery through these new activities alone is capped at 65/100. Compatibility tests use representative V0.1 records, not a copy of a user's private database.
